## Customer Behavior Analysis: EDA and Hypothesis Testing

Анализ данных клиентской базы для выявления факторов, влияющих на покупательскую способность, и формулировки продуктовых гипотез для сегментации аудитории.

## Данные
- Источник: открытый датасет (Mall Customers)
- Объем: 200 клиентов

## Ггипотезы
1. H1 (Возраст): Существует отрицательная корреляция между возрастом и индексом расходов
2. H2 (Доход): Годовой доход положительно коррелирует с индексом расходов
3. H3 (Пол): Гендерная принадлежность значимо влияет на паттерны расходов

## Результаты проверки гипотез
- H1:Подтверждена частично — выявлена слабая отрицательная корреляция
- H2: Опровергнута — высокий доход не гарантирует высокий индекс расходов
- H3: Опровергнута — паттерны мужчин и женщин практически полностью перекрываются

## Бизнес-инсайты
1. Опираться на пол или возраст при сегментации неэффективно. Важнее поведенческие метрики (история трат).
2. Индекс расходов имеет два явных пика (1-30 и 70-100) — два фундаментально разных типа клиентов.
3. Для клиентов с высоким доходом, но низким Spending Score нужны триггеры на рациональность, а для клиентов с высоким Spending Score — триггеры на эмоции и новизну.
